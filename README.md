# ShootZombie
## 概要
HAL東京在学中、2年生後半に制作した作品です。
ジャンル：TPS(三人称視点シューティングゲーム)
言語：C++
API：DirectX 9
操作：キーボードとマウス
制作期間：3ヶ月
担当箇所：全実装(個人製作)

## 実装内容
・3Dキャラクター制御
・オブジェクト及び地面との当たり判定
・カメラ制御
・敵の移動アルゴリズム
・照準・発射、及び攻撃の当たり判定

## 操作説明
<<タイトル画面>>
メニュー項目の選択 : マウスクリック
<<ゲーム画面>>
移動キー : W/A/S/D
走る : 左SHIFT + 移動キー
照準 : マウス右ボタン
シュート : 照準 + マウス左ボタン
カメラ操作 : マウス
リロード : Rキー
武器切り替え : 数字キー1 / 数字キー2 / 数字キー3
